# Enapter EMS Toolkit 3.0 — Landing Page

A modern, responsive landing page for the **Enapter Energy Management System Toolkit 3.0**, built with [Astro](https://astro.build/) and [Tailwind CSS](https://tailwindcss.com/).

---

## 🚀 Tech Stack

- **Framework:** [Astro](https://astro.build/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Language:** TypeScript
- **Deployment:** GitHub Pages

---

## 📦 Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
git clone https://github.com/Sam-tech94/enapter-ems-toolkit.git
cd enapter-ems-toolkit
npm install
```

### Development

```bash
npm run dev
```

Opens at `http://localhost:4321`

### Build

```bash
npm run build
```

Output goes to the `dist/` folder.

### Preview Production Build

```bash
npm run preview
```

## 📁 Project Structure

```
enapter-ems-toolkit/
├── public/             # Static assets (images, fonts, icons)
├── src/
│   ├── components/     # Reusable UI components
│   ├── layouts/        # Page layouts
│   └── pages/          # Astro pages (routes)
├── astro.config.mjs    # Astro configuration
├── tailwind.config.mjs # Tailwind configuration
└── tsconfig.json       # TypeScript configuration
```

---

## ✏️ Customization

- **Content:** Edit files in `src/pages/` and `src/components/`
- **Colors/Fonts:** Update `tailwind.config.mjs`
- **Assets:** Place images and files in `public/`
